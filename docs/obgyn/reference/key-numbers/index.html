★ نکات پرتکرار

  • انقباضات براکستون‌هیکس → بدون درد، بدون دیلاتاسیون، شایع‌تر در مولتی‌پار.
  • حلقه‌ی باندل → حلقه‌ی انقباضی پاتولوژیک، هشدار عدم تناسب سری-لگنی (CPD) یا انسداد لیبر.
  • هماتوم رتروپلاسنتال → معلول جداشدگی جفت است، نه علت آن (به‌جز موارد نادر خونریزی).
  • میفه‌پریستون (RU-486) → آنتاگونیست گیرنده‌ی پروژسترون؛ نرم‌کننده‌ی سرویکس و محرک دیلاتاسیون.
  • فیدبک CRH–کورتیزول جنینی-جفتی → مثبت است، نه منفی.
  • ترتیب حرکات اصلی لیبر → آنگاژمان، نزول، فلکسیون، چرخش داخلی، اکستانسیون، چرخش خارجی، خروج.
  • آسنکلیتیسم شدید → از علل شایع CPD؛ آسنکلیتیسم متوسط طبیعی و شایع است.
  • اکثر موارد CPD ناشی از پوزیشن نامناسب سر است، نه واقعاً بزرگی بیش‌ازحد جنین.
  • مرحله‌ی نهفته‌ی طولانی → اندیکاسیون سزارین نیست.
  • نمایش صورت با منتوم خلفی (MP) → زایمان طبیعی امکان‌پذیر نیست؛ تبدیل دستی MP←MA توصیه نمی‌شود.
  • تنگی لگن میانی از تنگی ورودی شایع‌تر است؛ اغلب با فورسپس میانی یا سزارین اداره می‌شود.
  • کاهش تغییرپذیری → قابل‌اعتمادترین نشانه‌ی آشفتگی جنین.
  • شایع‌ترین علت تاکی‌کاردی جنین → تب مادر؛ شایع‌ترین نوع افت در لیبر → افت متغیر (فشردگی بندناف).
  • مکونیوم به‌تنهایی → نشانه‌ی اسیدمی جنین نیست؛ ساکشن روتین راه هوایی توصیه نمی‌شود (ACOG 2021).
  • پایش الکترونیک FHR در برابر سمع → میزان سزارین/زایمان ابزاری را بالا می‌برد، مرگ پری‌ناتال یا فلج مغزی را کاهش نمی‌دهد.
  • مانور مک‌رابرتز → انتخاب اول برای دیستوشی شانه؛ ابعاد لگن را افزایش نمی‌دهد بلکه لگن را می‌چرخاند.
  • هرگز کشش روی بندناف برای خارج‌کردن جفت اعمال نکنید → خطر وارونگی رحم.
  • دیستوشی شانه دقیقاً قابل پیش‌بینی/پیشگیری نیست؛ سزارین الکتیو یا القای زودهنگام صرفاً به دلیل شک به ماکروزومی توصیه نمی‌شود.
  • Stargazing (هیپراکستانسیون سر بریچ) → اندیکاسیون سزارین، خطر آسیب نخاعی در زایمان طبیعی.
  • دیس‌پلازی هیپ در بریچ شایع‌تر است و تحت‌تأثیر روش زایمان قرار نمی‌گیرد.
  • ECV → قبل از لیبر، ≥۳۷ هفته؛ عوارض جدی نادر (سزارین اورژانس ≤۰.۵٪).
  • وجود پرولاکتین برای شیردهی ضروری است؛ سندرم شیهان → فقدان قدرت شیردهی.
  • خونریزی تأخیری پس از زایمان = بین ۲۴ ساعت تا ۱۲ هفته پس از زایمان؛ اغلب ناشی از پسرفت غیرطبیعی محل جفت.
  • کورتاژ روتین در خون‌ریزی تأخیری توصیه نمی‌شود مگر احتباس جفت وجود داشته باشد.
  • آسیب عصب جلدی رانی جانبی → شایع‌ترین نوروپاتی زایمانی.
